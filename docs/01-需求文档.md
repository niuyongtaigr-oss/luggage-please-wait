## 1. 一句话定义

把「我要走」这个念头，交给陌生人审一遍。如果被劝退，还你一条今天能走的路。

## 2. 核心洞察（产品存在的唯一理由）

> 申请单上有一格，问的是「你其实不想面对什么」。
> 市面上所有离开类产品都在问「你要去哪」，这一格问的是「你在躲什么」。
> 大部分人写不出为什么想走，但都写得出不想回哪。

**推论：这一格必须是必填，且必须是页面上视觉重量最大的地方。**
任何削弱它的设计（选填、缩小、折叠到第二步）都是产品错误。

## 3. 和「钱包请等等」的差别

| 维度 | 钱包请等等 | 行李箱请等等 |
|---|---|---|
| 拦的动作 | 你的手。手缩回来，事就过去了 | 你的走。一个人拎起箱子，说明他真的要离开现在这个地方 |
| 时间尺度 | 一次冲动，几十块 | 几天假、一个月房租、一个学期 |
| 审完之后 | 给你一句判决 | 给你一条今天就能走的路 |

**一句话记住：钱包拦的是手，行李箱拦的是走。这个决定，没有人替他做过。**

## 4. 产品立场（三条硬约束）

1. **不决定，只说话。** 决定权最后一下仍然在当事人手里。
2. **审批理由只能由人填写，模型不代写。** 陌生人的那句话是这个产品唯一不可替代的东西。
3. **产品里的 AI 只在你准备伤人的时候，轻轻碰一下你的手。**

第 1 条落在文案上：判决书必须有免责句。
第 2 条落在架构上：代码中不存在对理由正文的任何模型调用。
第 3 条落在交互上：护栏只提示，不拦截。

## 4.5 身份规则（谁算一个人）

产品上必须回答三个问题，严格度不同：

| 判断 | 用途 | 严格度 |
|---|---|---|
| 不是自己 | 不能给自己投票 | **高** |
| 不同的人 | 「41 个人看了」要诚实 | 中 |
| 同一个人 | 「你已经审过这份了」、回来看自己的判决 | 低 |

**规则：**

1. **一个人 = 一台设备 + 这一轮。** 用匿名设备 ID（cookie + localStorage 双写），不注册、不登录、不留手机号。
2. **一个人对一份申请只能有一句。** 数据库唯一索引兜底，不靠前端判断。
3. **不能审自己。** `applications.owner_device ≠ reviewer_device`。
4. **「41 个人」= 去重后的设备数**，不是浏览数，不是投票数。
5. **判决属于申请，不属于人。** 回来看判决靠设备 ID 匹配申请归属，不需要账号。
6. **「以审换审」是最强的身份约束**：想看自己的判决，必须先审一份别人的。

**明确不做：** 手机号、微信登录、实名、人机验证、IP 去重。

理由写在技术方案 §6.6：这个产品的敌人不是刷票团伙，是「没人愿意当审批人」。为防作弊引入登录，等于把 90% 的人挡在门外。

**一个必踩的坑：** 路演现场所有人同一个 WiFi，出口 IP 相同——**IP 绝对不能用来计数**。

## 5. 四页规格

### PAGE 01 · APPLY 交申请 ✅

| 项 | 规格 |
|---|---|
| 标题 | 你现在要离开哪？ |
| 副标 | 一句话就行。说不清也没关系。 |
| 场景 | 五选一：旅行 / 求学 / 出差 / 租房 / **说不清** |
| 我要离开哪 | 必填，≤24 字 |
| 为什么想走 | **选填**，≤40 字 |
| 如果不去，我会怎样 | 必填，≤40 字 |
| 我其实不想面对什么 | **必填**，≤40 字，带「我说不清」按钮 |
| 主按钮 | 交上去，让别人说一句 |
| 提交后 | 幕布：箱子滑上传送带，计数 0→47，文案「你的申请已放入今天 47 份里」 |

**为什么加「说不清」：** 这一格是灵魂，不能选填；但逼人写会劝退。给一个合法的「不知道」，两头都守住。

**校验：** 四个必填项为空时，抖动定位到第一个空格，顶部提示「还差 N 项」。

---

### PAGE 02 · REVIEW 审批 ✅

| 项 | 规格 |
|---|---|
| 顶部 | 今天第 12 份 · 等待你的判断 |
| 规则句 | 你交的第 47 份还在转盘上。先帮一个人看一份，这就是你的票。 |
| 卡片 | 只显示别人写的四格，标注「陌生人 · 匿名」 |
| 身份 | 三张牌：过来人 / 你的身体 / 你的钱包 |
| 投票 | 去吧 / 再想想（盖章） |
| 理由 | **必填**，≤60 字，不填不能投 |
| 护栏 | 命中词库浮提示，**不拦截** |
| 追加格 | **选填，仅当投「再想想」时出现**：如果他先不走，你觉得他可以先去哪？ |

**渐进披露顺序（这是演示节奏的骨架）：**

```
选身份 → 才解锁投票 → 投完 → 才出现理由框 → 写完 → 提交按钮才变绿 → 提交 → 才盖章
```

每步只做一件事。少一步，台上就会乱。

**身份必须真的改变产品**（不能是装饰）：

| 身份 | 去吧 的副标 | 再想想 的副标 | 理由框提示 |
|---|---|---|---|
| 过来人 | 我当年也走过 | 我当年没走成 | 我五年前也这样，后来…… |
| 你的身体 | 你扛得住 | 你上周才说睡不好 | 你上周才说睡不好 |
| 你的钱包 | 钱还够 | 押一付三，你还有多少 | 押一付三，你还有多少 |

**护栏规格：**

- 词库约 40 条，三类：羞辱 / 说教 / 嘲讽
- 命中后浮出一句「这句话可能有点重，要不要再读一遍？」，标注「AI 护栏 · 本地词库 · 不拦截」
- **发送按钮照常可点**，一个字都不改用户的话
- 全部本地判断，不发任何请求，断网可复现

### PAGE 03 · VERDICT 判决书 ✅

| 项 | 规格 |
|---|---|
| 四行大字 | 你想离开的 / 你真正想躲的 / 41 个人看了 / 27 个人说再想想 |
| 三类声音 | 劝走 / 劝留 / 给小路，各一句，各带身份落款 |
| 免责句 | 这只是 41 个人说的话，不是判决。走不走，最后一下还是你自己的手。 |
| 页脚小字 | 上一轮 · 2026-10-22 23:40 |
| 按钮 | 那我今天可以先做点什么 |
| 撕票动效 | 虚线撕口 + 两侧半圆缺口 + 存根左移淡出 |

**为什么是三类声音而不是「最高赞一句」：**
点赞机制天然奖励最刻薄的那句话。改成按态度聚类、每类各取一句，既去掉了这个偏差，又让「劝走」和「劝留」同时在场——这才是不替人做决定。

**为什么写「上一轮」：**
演示时「我刚交的申请」不可能已经有 41 个人看完。写死上一轮的日期，时间线才自洽。评委追问「41 个人哪来的」，指一下那行小字就过去了。

---

### PAGE 04 · SWAP 换一条 ✅

| 项 | 规格 |
|---|---|
| 标题 | 分支：多数再想想 →「走不成，可以先换一条」；多数去吧 →「那就走，走之前先装一条进去」 |
| 副标 | 别人给你的，不是建议，是一条能用的事。 |
| 路线卡 | 3 张，正面：情绪 + 线路名 + 里程站数 + 一条能用的事；背面：验证人数 + 值得人数 + 来源 |
| 按钮 | 再抽一条 / 我也交一条 |
| 小路表单 | 三格：你在哪 / 待了多久 / 一条能用的事 |

**三张路线卡（情绪映射写死）：**

| 情绪 | 线路 | 里程 | 一条能用的事 | 来源 |
|---|---|---|---|---|
| 想消失 | 杨浦滨江线 | 4.1 km · 3 站 | 这座桥 1993 年 10 月 23 日通车。今天它过生日。 | 公开史料 |
| 想安静 | 愚园线 | 3.2 km · 4 站 | 这一带真正安静的咖啡馆都在二楼。 | 居住经验 |
| 想热闹 | 外滩 · 北苏州河线 | 2.8 km · 4 站 | 外滩的楼都朝西。下午四点去，光是从江那边打过来的。 | 公开史料 |

**演示固定第一张（杨浦滨江线）**，走位第 8 步要能把「1993 年 10 月 23 日」读出来。

## 6. 数据策略

| 策略 | 做法 |
|---|---|
| 7 条预置池 | 写死在 data.js，演示固定第 3 条 |
| 判决书写成上一轮 | 页脚小字 + 口头补一句「昨晚跑通的那一轮」 |
| 三类声音各一句 | 预置，不做真实聚合 |
| 来源标注 | 每张卡右下角 10px 灰字：公开史料 / 居住经验·未核实 |
| DEMO POOL | 右下角常驻角标 |
| 零接口 | 所有数字写死，运行时不发任何请求 |

**逻辑：把「编的数据」提前印在页面上，诚实变成设计语言，评委的追问就没有落点。**

## 7. 匹配规则

```
同场景优先 → 全池兜底 → 取第一条
演示模式（默认）：锁死第 3 条，保证可预测
?live=1：走真实匹配
```

**不做同地点匹配。** 两个理由：隐私（同城的人凑一起，本来就快被认出来了）+ 价值（同地点 = 同温层，给不出「过来人」的视角）。

## 8. 非功能需求

| 项 | 要求 |
|---|---|
| 断网 | 全部功能可用，不发任何外部请求 |
| 依赖 | 零。无字体下载、无图片、无 CDN |
| 分辨率 | 1280×720 / 1920×1080 各测一遍，1000px 以上双栏一屏可见 |
| 手机 | 单栏，版面不塌 |
| 可预测 | 同一操作路径，永远得到同一结果 |
| 无障碍 | 键盘可走完全程、焦点可见、prefers-reduced-motion 适配 |

## 9. 验收标准

1. 断网状态下，只用 Ctrl+K，四页能完整走通
2. HUD 数字 47 / 41 / 27 全部正确
3. 伤人预警能弹一次，且发送按钮仍然可点
4. 路线卡能翻面，杨浦滨江线能出，「1993 年 10 月 23 日」能读出来
5. 手机能打开线上链接，版面不塌
6. 3 分钟剧本掐表两遍，误差不超过 10 秒
7. 被问「41 个人怎么算的」时，能在 20 秒内说清身份模型（见 §4.5）

## 10. 明确不做

积分、等级、连击、排行榜、抽卡概率、音效。

理由：数值系统会把「陌生人写的一句话」稀释成可刷的分数，而且两小时做不完。
